🟢 2. flex-grow

This is one of the most important properties.

Definition

It tells an item

"How much of the extra available space should I take?"
Grow

↓

Take Extra Space

🟢 3. flex-shrink

Default:

flex-shrink:1;

Definition:

When there isn't enough space,

how much should the item shrink?
Shrink

↓

Become Smaller
flex-shrink: 1 (default) → This box is allowed to shrink.
flex-shrink: 0 → This box is NOT allowed to shrink.

The value matters.

🟢 4. flex-basis

This one confuses everyone initially.

Think of it as:

The starting size of a flex item before flex-grow or flex-shrink is applied.
